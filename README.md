The one-sentence apology your agent owes you: an AI assistant owns up to correcting the grammar in a condolence card — and signing it "with sympathy and an Oxford comma."

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```

The program writes exactly one sentence (108 characters) to `$MAKEFUN_OUTPUT_DIR/entry.txt`.
